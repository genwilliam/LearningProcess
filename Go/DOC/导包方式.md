###### 导包方式：

在 Go 语言中，导入包（importing packages）是通过以下几种方式实现的：

1. **标准导入** 这是最常见的导入方式，用于导入标准库或第三方库的包。
    

 import "fmt"

2. **多包导入** 如果需要导入多个包，可以在 `import` 语句中使用圆括号将它们一行行列出，保持代码的整洁。
    

 import (  
     "fmt"  
     "os"  
     "math"  
 )

3. **别名导入** 你可以为导入的包指定别名，这在包名较长或者与当前作用域的名字冲突时特别有用。
    

 import f "fmt"

4. **匿名导入** 如果你只是想调用包中的 `init()` 函数或进行副作用操作，而不直接引用包中的任何对象，可以使用匿名导入。
    

 import _ "some/package"

5. **相对导入** 相对导入适用于同一模块内的包。虽然 Go 并不推荐使用相对路径导入，但在特定情况下仍可使用。这种方式主要用于模块内的子包，适合在本地开发环境中。
    

 import "./utils"

6. **使用 Go Modules 时的导入** 如果你使用 Go Modules 管理依赖，导入包时会使用模块路径来指定依赖版本。Go Modules 通过 `go.mod` 文件管理依赖版本。
    

 import "github.com/user/repo/package"
