# **Git 学习笔记**

Git，是每个程序员都绕不开的工具。刚开始我也只是直接在 GitHub 上点点点，上传文件、创建文件夹，看似简单，但随着项目越来越大，这种方式真的不够用了。

在这个笔记里，我记录了自己从 Git 小白到熟练使用的整个过程，包括常用命令、分支管理、冲突解决和实战经验。希望你也能通过这些内容，掌握 Git 的核心操作。

---

## **为什么要学 Git？**

想象一下这样一个场景：

你在做一个项目，今天修改了几行代码，明天又改了其他地方。突然，发现前天写的功能出问题了，你想回到之前的版本，但找不到正确的文件。或者你和同事协作开发，代码一上传就冲突不断，整个流程乱成一团。

这就是没有版本控制的痛点：

- 文件上传慢，容易出错
- 改了代码不知道改了哪些地方
- 想回到之前的版本很困难
- 多人协作变成噩梦

Git 的出现，正好解决了这些问题。掌握 Git，你就能轻松管理版本、跟踪修改、和团队协作无障碍。

## **实用小贴士**

- > 每次提交前先 pull 一下，避免冲突

- > commit 信息要写清楚，方便回溯

- > 养成经常提交的习惯，不要积累太多改动

- > 重要操作前备份分支

## **总结**

Git 是团队协作和个人开发不可或缺的工具。掌握它后，你可以：

- 随时回溯到任意版本
- 清楚每一次改动的记录
- 和团队顺畅协作

记住，不要害怕搞错，Git 总能帮你恢复。多练习，多尝试，慢慢就熟练了。
