# **Linux 进程与作业控制全面指南**

Linux 是一个多任务操作系统，而进程是系统运行的核心。理解进程如何创建、运行、终止，以及如何与作业和信号互动，对于深入掌握 Linux 至关重要。本文将详细介绍进程相关的概念、命令和操作技巧。

## **1. 进程是什么？**



简单说，**进程就是系统上正在运行的程序**。每个进程都有：



- **PID（Process ID）**：唯一的进程标识
- **PPID（Parent PID）**：父进程标识
- **UID/GID**：所属用户和组



Linux 内核负责管理所有进程，包括分配 CPU、内存和 I/O 资源，以及监控它们的状态。



查看当前进程：

```
$ ps
```

输出示例：

```
PID        TTY     STAT   TIME          CMD
41230    pts/4    Ss        00:00:00     bash
51224    pts/4    R+        00:00:00     ps
```

字段解释：



- **PID**：进程 ID
- **TTY**：进程所在终端
- **STAT**：进程状态
- **TIME**：CPU 总使用时间
- **CMD**：运行的命令

如果想看所有进程及详细信息，可以使用：

```
$ ps aux
```



- **a**：显示所有进程（包括其他用户的）
- **u**：显示详细信息
- **x**：显示没有终端的进程（守护进程）



常用字段：

| **字段** | **含义**         |
| -------- | ---------------- |
| USER     | 进程所属用户     |
| PID      | 进程 ID          |
| %CPU     | CPU 占用比例     |
| %MEM     | 占用物理内存比例 |
| VSZ      | 虚拟内存使用量   |
| RSS      | 常驻内存大小     |
| TTY      | 控制终端         |
| STAT     | 状态             |
| START    | 启动时间         |
| TIME     | 累计 CPU 时间    |
| COMMAND  | 执行命令         |

> 小提示：如果觉得 ps 输出太多，可以用 ps -eo pid,ppid,cmd,%mem,%cpu 只看最关心的字段。

## **2. 控制终端（TTY）**



进程通常绑定到一个终端：



- **常规终端**：虚拟控制台（Ctrl-Alt-F1~F6）
- **伪终端（PTS）**：我们平时用的终端模拟器窗口



守护进程通常没有控制终端（TTY 显示 ?），它们在后台运行。



> 例如，关闭终端窗口时绑定在该终端的进程通常也会被终止，而守护进程不会。



## **3. 进程详细信息与内核角色**



内核会跟踪每个进程的状态、资源使用、信号处理等。每个进程都是程序运行的实例：

```
$ ps aux | grep cat
```

即使同时启动多个 cat 进程，它们也是独立的 PID，内核独立管理。



### **内核跟踪的信息包括：**



- 进程状态
- 使用的资源
- 所有者信息
- 信号处理方式
- CPU 时间片分配情况



## 4. 进程创建**



新进程通常由已有进程通过 **fork** 生成，fork 会复制父进程的几乎所有信息，生成一个新 PID。随后，子进程可以使用 **execve** 启动一个新程序，替换原有内存空间。

```
$ ps l
```

你会看到 **PPID** 列，显示父进程 ID。



- 系统启动时，**init**（PID 1）是所有进程的“母亲”，负责生成系统守护进程。

## **5. 进程终止**



进程退出时会释放资源，使用 _exit 系统调用告知内核退出状态：



- 状态 **0** 表示成功
- 父进程必须调用 **wait** 获取子进程终止状态



### **特殊情况**

- **孤儿进程**：父进程先终止，init 收养
- **僵尸进程**：子进程已终止，但父进程未调用 wait



终止进程也可以使用信号：

```
$ kill PID       # 发送 SIGTERM
$ kill -9 PID    # 强制终止 SIGKILL
```

## **6. 信号**



信号是进程间通信的方式，也用于通知异常事件。常见信号：

| **信号**     | **含义**           |
| ------------ | ------------------ |
| SIGHUP (1)   | 挂断，终端关闭     |
| SIGINT (2)   | Ctrl-C 中断        |
| SIGTERM (15) | 请求终止，允许清理 |
| SIGKILL (9)  | 强制杀死进程       |
| SIGSTOP      | 暂停进程           |

信号可以：



- 忽略
- 捕获并执行处理程序
- 终止进程
- 阻塞信号传递

## **7. Kill 命令**



终止进程的命令：

```
$ kill 12345      # 默认 SIGTERM
$ kill -9 12345   # 强制终止 SIGKILL
```

> SIGTERM 优雅终止，SIGKILL 强制终止，不会进行清理。

## **8. Niceness（CPU 优先级）**



多进程同时运行时，CPU 时间片轮转调度：



- **nice 值高** → 对 CPU 更“友好”，优先级低
- **nice 值低** → 想抢占更多 CPU



查看进程优先级：

```
$ top
```

NI 列显示 nice 值。



修改进程优先级：

```
$ nice -n 5 apt upgrade   # 新进程
$ renice 10 -p 3245       # 已有进程
```

## **9. 进程状态**



STAT 列常见值：



- **R**：运行中或可运行
- **S**：可中断睡眠（等待事件）
- **D**：不可中断睡眠
- **Z**：僵尸
- **T**：已停止

## **10. /proc 文件系统**



进程信息存储在 /proc 文件系统，每个进程都有自己的子目录：

```
$ ls /proc
$ cat /proc/12345/status
```

这里信息比 ps 更详细，是内核管理进程的主要方式。



> 小技巧：/proc/[PID]/cmdline 可以查看启动命令，/proc/[PID]/fd/ 可以查看打开的文件描述符。

## **11. 作业控制**



在终端运行长任务时，可以用作业控制保持 shell 可用：

### **后台运行**



```
$ sleep 1000 &
```



### **查看作业**



```
$ jobs
[1] Running sleep 1000 &
```



### **暂停并后台运行**



```
Ctrl-Z  # 暂停
$ bg    # 后台继续
```



### **前台运行**



```
$ fg %1
```



### **终止后台作业**



```
$ kill %1
```

## **12. 拓展知识**

### **1. 进程优先级和实时调度**



Linux 内核支持 **实时调度策略**（SCHED_FIFO、SCHED_RR），适用于对时间敏感的任务，例如音视频处理、工业控制。普通进程使用 SCHED_OTHER 调度。



### **2. 线程与进程**



Linux 线程本质上也是进程，共享内存空间，但每个线程有独立的 PID（实际上是 TID）。线程管理资源消耗更低，适合并行计算。

### **3. cgroups（控制组）**



现代 Linux 使用 cgroups 限制进程 CPU、内存、I/O 使用，避免单个进程占满系统资源。



### **4. 守护进程最佳实践**



- 不绑定终端
- 写 PID 文件方便管理
- 使用日志文件而非终端输出

## **总结**



掌握进程与作业控制，你将理解 Linux 的核心运行机制。通过 ps、top、kill、nice、renice、作业控制命令以及 /proc 文件系统，你可以：



- 查看、监控、管理进程
- 控制 CPU 分配
- 后台运行任务
- 安全处理僵尸和孤儿进程



慢慢实践，你会发现 Linux 的多任务管理既强大又灵活。
