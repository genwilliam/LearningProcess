##### 如何找到文件
使用 `find` 命令来搜索文件的路径。比如，假设你知道文件的名字，想要在整个文件系统中找它，你可以使用以下命令：

```bash
find / -name "文件名"
```

其中，`/` 表示从根目录开始搜索，`-name` 后面跟的是你要查找的文件名。

如果你知道文件的某些部分名字，或者不记得完整文件名，也可以使用通配符。例如：

```bash
find / -name "*部分文件名*"
```

如果你只想在某个特定目录下查找，比如 `/home/user`，可以改成：

```bash
find /home/user -name "文件名"
```

此外，如果你知道文件的大致类型，可以用 `-type` 选项来指定查找文件类型，比如查找所有的文件：

```bash
find / -type f -name "文件名"
```

或者查找所有的目录：

```bash
find / -type d -name "目录名"
```


##### 权限问题
1.  权限类型：
- **读（r）**：允许查看文件内容。对于目录，允许列出其中的文件。
- **写（w）**：允许修改文件内容。对于目录，允许在该目录中创建、删除或重命名文件。
- **执行（x）**：允许执行文件，通常用于可执行程序或脚本。如果是目录，表示允许进入该目录。

2. 用户类别：
- **所有者（Owner）**：文件的创建者或被指定为文件所有者的用户。
- **组（Group）**：文件所有者所属的用户组。
- **其他用户（Others）**：不属于文件所有者或所属组的所有其他用户。

3. 权限表示方式：
- 权限通常以三组字符表示，分别对应所有者、组和其他用户。例如：
	-  `rwxr-xr--`：表示文件的所有者有读、写、执行权限，组用户有读、执行权限，其他用户只有读权限。

4. 修改权限：
使用`chmod`命令来改变文件的权限。例如：
- `chmod +x file`：给文件增加执行权限。
- `chmod 755 file`：设置所有者为读、写、执行权限，组和其他用户为读、执行权限。

5.  数字表示的权限
- `7` = `rwx`（读、写、执行）
- `6` = `rw-`（读、写）
- `5` = `r-x`（读、执行）
- `4` = `r--`（读）
