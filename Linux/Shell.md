##### 双引号和单引号
- 双引号会对变量进行变量和命令的解析，也就是进行替换
- 单引号不会对变量和命令进行解析，即不替换
```shell
num=5
echo "The number is $num"  # 输出The number is 5
echo 'The number is $num' #输出The number is $num
```

##### 关于expr
`expr` 是一个用于执行算术计算的命令，但它需要正确的语法和格式才能正确执行。
###### 代码 1

```bash
readonly a=3.14
echo "expr $a + 2"
```

这里有几个问题：

1. `readonly` 会将变量 `a` 设置为只读，没问题。
2. 使用 `expr` 时，字符串应该没有空格，尤其是浮动变量。`expr` 默认只能处理整数计算，对于浮动数（像 `3.14` 这样的值），它无法处理。
3. 正确的用法应该避免空格，并且对于浮动数，最好用其他方法（比如 `bc`）进行处理。

###### 代码 2

```bash
b=6
echo "expr $b + $a"
```

问题相同，`expr` 不能处理浮动数，虽然你定义了一个整数 `b`，但在执行加法时，`$a` 是浮动数，它会导致错误。

###### 正确的解决方案

你可以使用 `bc`（一个计算器程序）来处理浮动数。以下是如何修改代码：

```bash
readonly a=3.14
echo "scale=2; $a + 2" | bc

b=6
echo "$b + $a" | bc
```

在这段代码中：

`scale` 是 `bc`（基本计算器）命令中的一个参数，用于设置小数点后的精度。具体来说，`scale` 控制了在执行浮动数运算时，结果中小数部分的位数。

- **`scale=2`** 表示将计算结果的小数部分保留两位数字。
- **`scale=0`** 则表示不保留小数部分（即结果是整数）。

###### 为什么需要加分号？

在 `bc` 中，表达式和命令必须用分号 `;` 来分隔。如果你想在同一行上同时指定 `scale` 和进行计算，就需要使用分号来分开它们。例如：

```bash
echo "scale=2; $a + 2" | bc
```

这里，`scale=2` 设置了精度，而 `;` 后面的 `$a + 2` 是你要计算的表达式。`bc` 会按照 `scale` 的值来处理这个表达式的结果。

如果没有分号，`bc` 会认为 `scale=2` 是一个单独的命令，而 `$a + 2` 是另一个命令，会导致错误。

- `scale=2` 设置小数点后精度为 2 位（可根据需要调整）。
- 使用 `echo` 将表达式传递给 `bc` 进行计算。
