# Linux 管道与 tee 命令

在 Linux 中，命令的输出不仅可以重定向到文件，还能通过 **管道（pipe）** 传递给其他命令，实现强大的组合操作。本文介绍了两个常见的 I/O 工具：`|`（管道操作符）与 `tee`。

## 管道操作符 `|`

在命令行中，竖线 `|` 被称为 **管道**。  
它的作用是：

> 将前一个命令的输出（stdout）作为下一个命令的输入（stdin）。

举个例子：

```bash
ls -la /etc
```

这条命令会输出一个很长的目录列表，但信息太多，不便阅读。

我们可以使用管道将它交给 less：

```
ls -la /etc | less
```

这样输出内容会分页显示，更加直观。

ls 产生的输出并没有写入文件，而是直接通过管道传给了 less。

## **tee 命令：分流输出**

有时候，我们既想在屏幕上看到输出，又想把它保存到文件中。

这时就可以使用 **tee 命令**。

```
ls | tee demo.txt
```

执行后：

- 终端上会正常显示 ls 的输出；
- 同时内容也会被写入 demo.txt 文件。

如果想将输出追加到文件，而不是覆盖原内容：

```
ls | tee -a demo.txt
```

## **总结**

| **命令**    | **作用**             |
| ----------- | -------------------- |
| tee file    | 同时输出到屏幕和文件 |
| tee -a file | 追加输出到文件       |
|             |                      |

通过组合使用 | 和 tee，可以轻松实现输出查看、保存、过滤、统计等操作

## 关于 tee 流程

```text
ls ──stdout──▶ tee peanuts.txt ──stdout──▶ 终端
                      │
                      └──▶ peanuts.txt（文件）
```
