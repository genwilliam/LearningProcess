### 1. `755` 代表 `rwxr-xr-x` 的含义

在 Linux 中，权限由 3 组组成，每组 3 个权限位：

|权限位|读（r=4）|写（w=2）|执行（x=1）|
|---|---|---|---|
|所有者（User）|✅|✅|✅|
|组用户（Group）|✅|❌|✅|
|其他用户（Other）|✅|❌|✅|

权限使用 **八进制数** 来表示，每位代表一组权限：

- `rwx` = `4 + 2 + 1` = `7`
- `r-x` = `4 + 0 + 1` = `5`
- `r-x` = `4 + 0 + 1` = `5`

所以：

```bash
chmod 755 filename
```

等价于：

```bash
chmod u=rwx,g=rx,o=rx filename
```

即：

- **所有者（User, `u`）** 有 `rwx`（可读、可写、可执行）
- **组用户（Group, `g`）** 只有 `r-x`（可读、可执行，不能写）
- **其他用户（Other, `o`）** 也只有 `r-x`（可读、可执行，不能写）

---

### 2. 用户类别及其字母表示

Linux 中的文件权限涉及 3 类用户：

|用户类别|代表字母|说明|
|---|---|---|
|所有者（User）|`u`|文件的拥有者，通常是创建该文件的用户|
|组用户（Group）|`g`|文件所属的用户组中的成员|
|其他用户（Other）|`o`|除了所有者和组用户之外的所有用户|

除了 `u、g、o` 这些单独的用户类别，还可以使用 `a`（all）表示所有用户：

```bash
chmod a+r file   # 给所有用户添加读权限
chmod a-x file   # 取消所有用户的执行权限

```

### 补充示例

| 数字权限  | 符号权限        | 解释                         |
| ----- | ----------- | -------------------------- |
| `777` | `rwxrwxrwx` | 所有人都有读、写、执行权限（⚠️不安全）       |
| `755` | `rwxr-xr-x` | 只有所有者可以修改，其他用户只能读取和执行      |
| `644` | `rw-r--r--` | 只有所有者可读写，其他用户只能读取（常用于文本文件） |
| `600` | `rw-------` | 只有所有者可读写（隐私文件，如 SSH 密钥）    |
| `400` | `r--------` | 只有所有者可读，其他人无权限             |
